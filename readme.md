## Free Android app for memorizing verses 
in english or german.

Made with Android Studio Android Studio in 2025/26

use import project


Also in playstore(2026). https://play.google.com/store/apps/details?id=trust.jesus.discover



Features

• 4 exercises for learning/reflecting on Bible verses

• Speech recognition exercise, reciting verses with special review

• Discovery page with random verse, 3 daily verses

• Word search in the Bible as a list, for use at any time

• With a small verse list, also editable and shareable

• With integrated Bible, with extra read-aloud options.
